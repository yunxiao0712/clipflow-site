Open ClipFlow

ClipFlow lives in the macOS menu bar. Click its icon or press the default shortcut ⌘⇧V. There is no Dock icon. The shortcut can be changed in Settings.

A copied item is missing

Check that recording is not paused, clear the search field, and check the Favorites and pinboard filters. Sensitive-content filtering and history capacity can also affect saved items.

A file cannot be copied again

The original file must still exist and be accessible. Use Files & Backups to grant access to its folder if needed. Moving to another volume or deleting a file can break the reference; ClipFlow is not a file backup service.

Recover history after a sandbox upgrade

First export the current library from Files & Backups. Then use Import History to choose your earlier library.json. Import merges records and keeps current preferences. Keep your original backup until you verify the result.

Send a useful support request

Include the app version, macOS version, steps to reproduce, and the expected result. Redact screenshots. Do not attach your full history, passwords, access bookmarks, identity documents or payment details.
