隐私政策

2026-10-22 · 王佳琛

剪贴板数据留在你的 Mac 上

启用记录时，ClipFlow 读取新复制的文字、图片和文件引用，生成可搜索的本地历史。记录可能包含来源应用名称、时间、标题、收藏、归档、缩略图和文件访问书签。当前应用没有开发者服务器、账号、云同步、广告、追踪、统计分析或自动崩溃上传功能，不会向开发者传输剪贴板历史。

文件与权限

ClipFlow 保留已复制文件的引用和预览，不会为每个原文件制作永久副本。复制文件时，macOS 可能授予应用访问权限。你也可以在“文件与备份”中额外授权所选目录的只读访问，并移除这些额外授权。移除授权不会删除历史，也不一定撤销 macOS 通过其他途径授予的访问权限。已删除的文件和部分移动后的文件可能无法再次访问。

存储与备份

历史以本地 JSON 文件保存在应用沙盒中，ClipFlow 不对其自行加密。设备安全及系统备份取决于你的 macOS 配置。导入导出会产生包含已保存历史的 JSON 文件，恢复备份也可能保留旧记录。请妥善保护这些文件，不要公开分享。

控制与删除

状态栏菜单的“暂停记录”会停止新增捕获。你可以删除单条卡片、清空历史、调整历史容量，以及选择是否开机启动。清空历史不会抹除另行导出的文件、恢复备份、系统备份或原始文件；如需删除，请分别处理这些副本。

敏感信息

可选的敏感内容过滤使用文本关键词，无法可靠识别所有密码、支付信息或其他秘密。复制敏感内容前请暂停记录，并删除不希望保留的卡片。

客服与变更

你主动联系客服时发送的邮箱、问题描述和附件等信息将用于处理请求。请不要发送私人剪贴板历史。这份说明适用于当前的本地应用；增加订阅、云服务或其他数据处理前，需要更新隐私信息。
